O design da Agenda do Coração Família, em um só lugar.

Esta página reúne cores, tipografia, componentes e regras de acessibilidade que vão orientar a futura Agenda de eventos do CCF: a lista cronológica de oficinas, encontros e atividades da organização, com uma página própria para cada evento — pensada primeiro para celular.

Cada peça aqui usa os tokens definidos em ccf_design_tokens.css. Contexto completo do projeto em AGENTS.md.

Marca

Três arquivos oficiais, cada um para um contexto. Nenhum deve ser redesenhado.

icon-ccf.png

Mascote-coração com o nome "Coração Família" escrito dentro dele, fundo transparente — não inclui a segunda linha manuscrita "CENTRO DE CONVIVÊNCIA FAMILIAR" que aparece nas logos lq/hq. Use em avatar de app, superfícies pequenas ou fundos escuros — como no rodapé institucional, mostrado no item l da seção Componentes. O favicon é uma peça própria (ainda não gerada), não um recorte deste arquivo.

logo-ccf-lq.png

Mascote + nome em letreiro vermelho manuscrito, resolução web. Uso padrão em cabeçalho e materiais digitais — sempre sobre fundo claro: o letreiro não tem contraste garantido em fundo escuro.

logo-ccf-hq.png

Mesmo conteúdo do lq, em alta resolução (cerca de 1,1 MB). Reservado para impressão e exportações de alta qualidade. Não carregar em página web comum — o peso do arquivo penaliza o carregamento.

Não fazer

  • Redesenhar, recolorir ou alterar as cores do mascote ou do letreiro.
  • Distorcer, espremer, alongar ou rotacionar qualquer um dos três arquivos.
  • Aplicar sombra, brilho (glow) ou modo de mescla diretamente sobre a imagem da marca — se precisar de destaque, aplique sombra no cartão/contêiner ao redor, nunca um filter na tag <img>.
  • Colar logo-ccf-lq.png sobre fundo escuro ou colorido sem testar o contraste do letreiro manuscrito.

Área de respiro e tamanho mínimo

  • Reserve uma margem livre ao redor da marca de aproximadamente 25% da largura da peça, em todos os lados.
  • Largura mínima do ícone isolado: 32px.
  • Largura mínima da logo com letreiro: 160px — abaixo disso o texto manuscrito fica ilegível.
  • Sempre carregar os PNGs por caminho relativo (src="icon-ccf.png"), nunca embutidos em base64.

Correção de contraste: verde-500 × verde-700

Nenhum dos dois verdes existe no logo — são extensões de interface para status. O rascunho anterior usava --ccf-p-green-500 com texto branco; essa combinação falha o contraste mínimo da WCAG. A correção pedida pelo projeto: texto branco passa a usar sempre --ccf-p-green-700. O 500 continua no sistema, mas só como fundo claro com texto escuro por cima.

Ao vivo

Pressione Tab a partir do topo da página (ou clique aqui e use Tab) até chegar neste botão para ver o anel de foco em ação.

Usa :focus-visible com var(--ccf-focus-ring) — nunca :focus sozinho, nunca outline:none sem substituto.

Movimento reduzido

Este documento inteiro respeita prefers-reduced-motion: transições, animações e a rolagem suave são desligadas quando o visitante pede menos movimento.

@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
Navegação mobile

O menu do cabeçalho colapsa abaixo de 768px e vira um botão único, já demonstrado no topo desta página. Todo alvo de toque no menu tem no mínimo 44px — aqui, 48px (--ccf-button-min-height).

Nunca só cor

Todo status de evento leva ícone e texto junto com a cor — quem não distingue cores ainda entende a etiqueta. Ver as 5 variantes de status na seção Componentes.

Contraste como regra, não exceção

Os números desta tabela vieram do cálculo real de cada combinação usada no sistema — nenhum foi estimado.

f. Detalhe do evento (página completa, preenchida)

Mockup de uma página de evento com todos os campos preenchidos: banner, título, badges, descrição, programação de um dia, convidados, local e ações. O banner abaixo é uma peça pronta (arte com texto embutido, como a organização costuma produzir); o título em HTML continua presente na página mesmo assim, para leitor de tela, SEO e para quando o banner for só uma foto sem texto. Card de evento e banner usam sempre --ccf-event-card-image-ratio/--ccf-banner-ratio em 1:1 (o mesmo formato quadrado das redes sociais), para reaproveitar direto a mesma arte de Instagram sem recorte.
